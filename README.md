# Home Appliances Ecommerce Website

A Java web application for a home appliances ecommerce website. I developed this project independently as part of my Diploma in Information Technology at TAR UMT.

## Technologies

- Java Servlets for backend request handling
- JSP for web pages
- GlassFish Server for running the application
- Apache Derby for database storage

## Running the Project

1. Clone or download this repository.
2. Open the project in a Java IDE.
3. Start Apache Derby and configure the database to match the application's connection settings.
4. Build and deploy the application to GlassFish Server.
5. Open the application's URL in your browser.
